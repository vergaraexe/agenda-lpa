# Agenda LPA
Etapa 1: hoja cuadriculada, encabezado dia + logo, lapiz/destacador/goma.
Etapa 2: guardado automatico por dia (files/agenda/AAAA-MM-DD/page_N.json), paginas por dia, navegacion entre dias.
Abrir en Android Studio, sincronizar Gradle y ejecutar en la tablet (depuracion USB).

## Obtener el APK sin Android Studio
1. Subir esta carpeta a un repositorio nuevo en GitHub (rama main).
2. Pestaña Actions > "Compilar APK" (se ejecuta sola al subir los archivos).
3. Al terminar, descargar el artefacto "AgendaLPA-apk" (contiene app-debug.apk).
4. Pasarlo a la tablet e instalarlo (permitir "instalar apps desconocidas").
